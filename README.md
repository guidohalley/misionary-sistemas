# misionary-sistemas

Landing de [misionary.dev](https://misionary.dev) — software factory de Misionary (Posadas, Misiones): sistemas a medida e integraciones.

## Stack

Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · OpenNext / Cloudflare

## Desarrollo

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000).

## Scripts

| Comando | Uso |
| --- | --- |
| `npm run dev` | Dev server |
| `npm run build:next` | Build Next |
| `npm run build` | Build OpenNext (Cloudflare) |
| `npm run lint` | ESLint |

## Branding

Marca local en `components/brand-mark.tsx` y `public/brand/misionary-mark.svg` (`currentColor`). Favicon / OG en `app/icon.*`, `app/apple-icon.png`, `app/opengraph-image.png`.
